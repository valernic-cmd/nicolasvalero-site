MISE À JOUR GITHUB — VERSION 5

1. Décompresse cette archive sur ton ordinateur.
2. Dans ton dépôt GitHub nicolasvalero-site, ouvre l’onglet Code.
3. Clique sur Ajouter un fichier > Téléverser des fichiers.
4. Glisse TOUT LE CONTENU du dossier décompressé (pas le fichier ZIP).
5. Attends que tous les fichiers soient chargés.
6. Message conseillé : Mise à jour V5 — bio, Octogônes, article et vidéo
7. Valide les modifications.
8. Attends 1 à 3 minutes puis actualise https://nicolasvalero.fr
